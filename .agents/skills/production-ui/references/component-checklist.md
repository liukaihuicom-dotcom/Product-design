# Component Checklist

## P0 Components

- Button: primary, secondary, ghost, danger, disabled, loading.
- Card: default, elevated, interactive, warning, success.
- Input: default, focus, disabled, error, success, amount affix.
- Select: readable selected value and disabled reason.
- StatusBadge: success, warning, danger, neutral, info.
- Alert: info, warning, danger, success.
- Table: loading, empty, error, right-aligned amounts, row actions.
- EmptyState: reason and next action.
- LoadingState: stable layout and duplicate-submission prevention.
- ErrorState: reason, next step, retry path.
