# 17-UI_QA.md

## Production UI QA v2.0

| Check | Pass Standard |
|---|---|
| Platform identified | Web/App/H5 is clearly identified |
| Token usage | No random color, spacing, radius, shadow |
| Layout | Follows platform layout rules |
| Typography | Amounts, titles, labels are readable |
| Components | Uses ui/business components |
| Icons | Uses icon library and Icon component |
| Forms | Labels, helper, error, disabled states complete |
| Tables | Web tables readable, App uses card lists |
| States | Default, loading, empty, error, success, failed, reviewing covered |
| API mapping | UI state matches API_STATE_MAP |
| I18N | Text allows expansion, currency/date format correct |
| Accessibility | Important states do not rely on color only |
| Motion | Loading and transitions are appropriate |
| Responsive | Desktop/mobile behavior is correct |
| Financial clarity | Amount, currency, account, status are explicit |
| Compliance clarity | Risk reason and next action are visible |

## Required Final Summary

Codex must summarize:

1. Target platform.
2. Files read.
3. Components reused.
4. Components created.
5. Tokens used.
6. States covered.
7. API fields mapped.
8. Responsive behavior.
9. Remaining manual review items.
