# 00-OVERVIEW.md

## Design System Goal

This design system supports Web and App production-grade UI prototypes for Broker SaaS, trading, KYC, funds, compliance, and partner portal products.

## Supported Platforms

| Platform | Description |
|---|---|
| web-admin | Internal admin backend |
| web-portal | User / partner web portal |
| app-ios | Native-like iOS app prototype |
| app-android | Native-like Android app prototype |
| h5-mobile | Mobile web / responsive H5 |

## Core Principles

1. Clarity over decoration.
2. Financial trust over visual novelty.
3. State completeness over default-only screens.
4. Token-driven design over random styling.
5. Component reuse over page-level duplication.
6. Platform-specific UX over one-size-fits-all UI.

## Product Domains

- KYC / CLM
- Liveness verification
- Deposit
- Withdrawal
- Wallet
- Transfer
- Trading account
- Copy trading
- Partner / IB portal
- Review center
- Compliance archive
- Reports

## Current Visual Direction

The current brand expression is Wise-inspired: bright green primary actions, forest-green hierarchy, green-tinted neutral surfaces, rounded controls, restrained iconography, and clear financial copy. Do not use Wise logos or protected brand assets.
