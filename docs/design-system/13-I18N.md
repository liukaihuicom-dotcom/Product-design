# 13-I18N.md

## I18N Goal

Support English, Chinese, Indonesian, and future languages without breaking layouts.

## Supported Languages

| Language | Code | Direction |
|---|---|---|
| English | en | LTR |
| Simplified Chinese | zh-CN | LTR |
| Indonesian | id-ID | LTR |

## Text Expansion

Design must allow 30% text expansion.

| Language | Risk |
|---|---|
| English | Baseline |
| Chinese | Shorter but dense |
| Indonesian | Often longer |
| German / future | Much longer |

## Currency Format

| Currency | Format |
|---|---|
| USD | USD 1,250.00 |
| IDR | IDR 10,000,000 |
| USC | USC 100,000 |
| JPY | JPY 100,000 |

## Date Format

| Context | Format |
|---|---|
| Web table | YYYY-MM-DD HH:mm |
| App detail | DD MMM YYYY, HH:mm |
| Audit log | YYYY-MM-DD HH:mm:ss |
| User-friendly | 13 May 2026 |

## Copy Rules

- Use short title + clear subtitle.
- Avoid vague messages like "Operation failed".
- Financial and compliance copy must be explicit.
- Button text should be action-oriented.
- Avoid long paragraphs on App; use expandable details.
