# 10-PATTERNS.md

This file extends `PATTERNS.md` for Design System v2.0.

## Web Patterns

| Page Type | Recommended Structure |
|---|---|
| Dashboard | Header + metrics + alerts + data cards + recent records |
| List / Records | Header + filters + table + pagination |
| Detail | Header + status + summary card + sections + timeline |
| Form | Header + form card + helper side panel + footer action |
| Review Center | Queue summary + filters + table + decision panel |

## App Patterns

| Page Type | Recommended Structure |
|---|---|
| Home | App header + summary cards + primary actions + recent list |
| Form | Header + step / fields + helper + sticky bottom CTA |
| Detail | Status summary + key info + timeline + bottom action |
| Records | Filter chips + card list + load more |
| Feedback | Icon + title + subtitle + primary CTA + secondary CTA |
| Selector | Bottom sheet |
