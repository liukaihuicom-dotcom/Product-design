# 01-DESIGN.md

This file extends `DESIGN.md` for Design System v2.0.

## Product Personality

Professional financial SaaS with a Wise-inspired visual tone: clear, direct, bright, and trustworthy.

## Cross-Platform Direction

| Platform | Design Goal |
|---|---|
| web-admin | Dense but readable operational workspace. |
| web-portal | Clear financial self-service with trustworthy guidance. |
| app-ios / app-android | Mobile-first account and money movement experience. |
| h5-mobile | Lightweight mobile web with app-like structure. |

## Visual Rules

- Use green-tinted neutrals and bright green accents through tokens.
- Keep surfaces simple and information-forward.
- Prefer useful status, risk, and money movement cues over decoration.
- Do not use generic dashboard gradients, playful illustrations, or random visual motifs.
- Preserve direct compliance language for blocked, failed, and reviewing states.

## Relationship To v1 Files

`DESIGN.md` remains the compatibility entry for existing v1 workflows. New v2 tasks should read this file after `00-OVERVIEW.md`.
