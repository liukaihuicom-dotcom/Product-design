# 04-TYPOGRAPHY.md

## Typography Goal

Financial products rely heavily on readable numbers, statuses, and operational text. Typography must prioritize clarity.

## Font Families

| Token | Usage |
|---|---|
| `--font-family-base` | Normal text |
| `--font-family-number` | Amounts, account IDs, transaction IDs, table numbers |

## Web Typography

| Style | Size / Line Height / Weight | Usage |
|---|---|---|
| Display | 32 / 40 / 600 | Dashboard hero metrics |
| Page Title | 24 / 32 / 600 | Page title |
| Section Title | 18 / 28 / 600 | Card / section title |
| Body | 14 / 22 / 400 | Default text |
| Body Strong | 14 / 22 / 600 | Important text |
| Caption | 12 / 18 / 400 | Metadata |

## App Typography

| Style | Size / Line Height / Weight | Usage |
|---|---|---|
| App Title | 20 / 28 / 600 | App page title |
| Section Title | 16 / 24 / 600 | Section title |
| Body | 14 / 22 / 400 | Normal text |
| Body Large | 16 / 24 / 400 | Important form text |
| Caption | 12 / 18 / 400 | Helper text |
| Amount Hero | 32 / 40 / 600 | Main amount input or balance |

## Financial Number Rules

| Type | Rule |
|---|---|
| Amount | Use number font, show currency |
| Balance | Align decimals, use strong weight |
| Percentage | Keep symbol close to number |
| Account ID | Use monospace if long |
| Transaction ID | Support copy action |
| Negative amount | Use danger color only when semantically negative |
| Pending amount | Use warning or info status nearby, not just color |
