# TOKENS.md

## 1. Token Layers

| Layer | Purpose |
|---|---|
| Base tokens | Raw values: colors, spacing, radius, font sizes. |
| Semantic tokens | Meaning-based usage: text-primary, bg-surface, border-default. |
| Component tokens | Component-specific usage: button-height-md, card-padding. |
